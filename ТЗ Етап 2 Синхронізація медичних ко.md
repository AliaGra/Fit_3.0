ТЗ Етап 2: Синхронізація медичних колонок
Джерело: ExerciseLibrary_v3_medical.xlsx  →  Supabase: таблиця exercises

Область змін:	Тільки медичні колонки таблиці exercises (6 полів)
Стратегія:	UPSERT по id — всі 114 вправ, повна синхронізація з xlsx
Файл-джерело:	data/ExerciseLibrary_v3_medical.xlsx  →  аркуш ExerciseLibrary
Поза скоупом:	Всі інші колонки exercises (назва, equipment, group тощо) — НЕ чіпати

1. Медичні колонки — структура
Шість колонок у таблиці exercises які оновлюються цим скриптом:

Колонка в БД	Колонка в xlsx	Призначення
medical_contraindications	medical_contraindications	Абсолютні заборони: MC-коди при яких вправа заборонена
medical_limitations	medical_limitations	Обмеження з примітками: MC-коди + як саме обмежити
safe_for	safe_for	Безпечно при: MC-коди при яких вправа дозволена
modifications	modifications	Як модифікувати вправу при певних обмеженнях
alternatives	alternatives	Альтернативні вправи при протипоказаннях
safety_notes	safety_notes	Загальні примітки безпеки незалежно від стану здоров'я

💡  Ці 6 колонок — єдине що змінюється. Всі інші поля exercises (id, name_ua, equipment_id, group1 тощо) скрипт не чіпає.

2. Файл-джерело
2.1 Розташування
project-root/data/ExerciseLibrary_v3_medical.xlsx

2.2 Структура xlsx
Аркуш: ExerciseLibrary. Перші 3 рядки — заголовки (пропустити при читанні):

Рядок	Вміст	Дія
1	Англійські ключі колонок (id, group1, name_ua…)	Використати як заголовки (header row)
2	Українські назви колонок	Пропустити
3	Описи колонок	Пропустити
4–117	Дані вправ (114 рядків)	Читати та синхронізувати

⚠️  Читати xlsx з параметром { range: 1 } — щоб рядок 1 (англійські ключі) став заголовком. Рядки 2 і 3 пропустити при обробці (перевіряти що id не порожній і не є описом).

3. Скрипт синхронізації
3.1 Файл
scripts/sync-medical.js

3.2 Код
// scripts/sync-medical.js
// Запуск: node scripts/sync-medical.js
// Синхронізує медичні колонки exercises з ExerciseLibrary_v3_medical.xlsx

const { createClient } = require('@supabase/supabase-js');
const XLSX = require('xlsx');
const path = require('path');

const supabase = createClient(
  process.env.SUPABASE_URL,
  process.env.SUPABASE_SERVICE_ROLE_KEY
);

// Медичні колонки — єдине що оновлюємо
const MEDICAL_COLS = [
  'medical_contraindications',
  'medical_limitations',
  'safe_for',
  'modifications',
  'alternatives',
  'safety_notes',
];

async function syncMedical() {
  // 1. Читаємо xlsx
  const wb = XLSX.readFile(
    path.join(__dirname, '../data/ExerciseLibrary_v3_medical.xlsx')
  );
  const ws = wb.Sheets['ExerciseLibrary'];

  // range: 1 — рядок 1 стає заголовком (англійські ключі)
  const allRows = XLSX.utils.sheet_to_json(ws, { range: 1, defval: null });

  // Пропустити службові рядки (рядки 2 і 3 — описи)
  // Вони потрапляють першими у масив — фільтруємо по id
  const rows = allRows.filter(r => {
    const id = r['id'];
    // Валідний id: N001–N999 або аналогічний формат
    return id && /^[A-Z]\d+$/.test(String(id).trim());
  });

  console.log(`Прочитано з xlsx: ${rows.length} вправ`);

  // 2. Формуємо масив для upsert — тільки id + медичні поля
  const updates = rows.map(r => {
    const obj = { id: String(r['id']).trim() };
    for (const col of MEDICAL_COLS) {
      const val = r[col];
      // Порожній рядок або null → зберігаємо як null
      obj[col] = (val === null || val === '' || val === undefined)
        ? null
        : String(val).trim();
    }
    return obj;
  });

  // 3. UPSERT — оновлює тільки вказані колонки, решта не змінюється
  const { error } = await supabase
    .from('exercises')
    .upsert(updates, {
      onConflict: 'id',
      ignoreDuplicates: false,
    });

  if (error) {
    console.error('❌ Помилка синхронізації:', error.message);
    process.exit(1);
  }

  console.log(`✅ Синхронізовано ${updates.length} вправ`);

  // 4. Перевірка — рахуємо порожні medical_contraindications
  const { count, error: checkError } = await supabase
    .from('exercises')
    .select('id', { count: 'exact', head: true })
    .is('medical_contraindications', null);

  if (checkError) {
    console.warn('⚠️  Не вдалось перевірити:', checkError.message);
  } else {
    console.log(`Вправ без medical_contraindications: ${count}`);
    if (count === 0) console.log('✅ Всі вправи мають медичні дані');
    else console.warn(`⚠️  ${count} вправ без медичних даних!`);
  }
}

syncMedical();
