# Підключення AI до FIT 3.0 — покрокова інструкція

Інструкція для тих, хто ніколи не підключав OpenAI API. Нічого складного — тільки копіювання ключа та додавання змінних у Railway.

---

## Крок 1. Отримати ключ OpenAI (API Key)

1. Зайди на сайт **https://platform.openai.com**  
   Якщо немає акаунту — зареєструйся (email + пароль).

2. Увійди в акаунт і перейди в розділ **API keys** (ключі API):  
   - У лівому меню: **API keys** або **Settings → API keys**,  
   - або пряме посилання: **https://platform.openai.com/api-keys**

3. Натисни кнопку **«Create new secret key»** (або «Create API key»).  
   - Можна вказати назву, наприклад: `FIT3 bot`.  
   - Підтверди створення.

4. **Важливо:** ключ покажуть **один раз** у вигляді рядка, що починається з `sk-...`  
   - Скопіюй його і збережи в безпечному місці (наприклад, у себе в нотатках).  
   - Якщо закриєш сторінку без копіювання — ключ доведеться створювати заново.

5. На **OpenAI** потрібна оплата (карта). Без поповнення балансу API не працюватиме.  
   - Для нашого бота витрати дуже малі (модель `gpt-4o-mini`): орієнтовно кілька доларів на місяць при активному використанні.  
   - Можна покласти, наприклад, $5–10 і стежити за витратами в розділі **Usage** на platform.openai.com.

---

## Крок 2. Додати таблицю в Supabase (якщо ще не додавала)

Бот зберігає логи AI-відповідей у таблиці `ai_generated_content`.

1. Відкрий проєкт у **Supabase**: https://supabase.com/dashboard  
2. У лівому меню вибери **SQL Editor**.  
3. Відкрий файл **`supabase_migration_ai_content.sql`** у папці проєкту.  
4. Скопіюй увесь текст з файлу і встав у вікно запиту в SQL Editor.  
5. Натисни **Run** (або Execute).  
6. Має з’явитися повідомлення, що таблиця створена. Якщо таблиця вже була — помилки не буде завдяки `IF NOT EXISTS`.

Перевірка: у лівому меню **Table Editor** має з’явитися таблиця **ai_generated_content**.

---

## Крок 3. Додати змінні середовища в Railway

1. Відкрий **Railway**: https://railway.app і увійди в акаунт.  
2. Відкрий **свій проєкт** (де розгорнутий бот FIT 3.0).  
3. Вибери **сервіс** (зазвичай один — твій бот).  
4. Перейди на вкладку **Variables** (або **Settings → Variables**).  
5. Додай змінні **по одній** (кнопка **+ New Variable** або **Add variable**):

   | Ім'я змінної   | Значення        | Примітка |
   |-----------------|-----------------|----------|
   | `OPENAI_API_KEY` | `sk-...`       | Вставити **свій** ключ з Кроку 1 (без лапок). |
   | `AI_ENABLED`     | `true`         | Саме латинськими літерами `true`. |
   | `AI_MODEL`       | `gpt-4o-mini`  | Можна не додавати — тоді використається значення за замовчуванням. |
   | `AI_MAX_TOKENS`  | `600`          | Опційно. |
   | `AI_TIMEOUT_MS`  | `10000`        | Опційно. |

   **Мінімум потрібно додати тільки дві змінні:**  
   - **OPENAI_API_KEY** — твій ключ.  
   - **AI_ENABLED** — `true`.

6. Збережи зміни. Railway зазвичай **перезапускає** сервіс після зміни Variables — почекай 1–2 хвилини.

---

## Крок 4. Перевірити, що AI увімкнено

**Важливо:** коментарі «💬 Тренер» з’являються **тільки в нових планах**, створених через **Авто-підбір** вже **після** підключення AI. Старі плани (створені до цього або вручну) коментарів не матимуть.

Після перезапуску бота:

1. **Генерація плану (Частина 3):**  
   У боті: Мої учні → вибери учня → Програма тренувань → **➕ Новий план** → **Авто-підбір** → **Генерувати**.  
   Після генерації відкрий **саме цей новий** план — під кожною вправою мають з’явитися рядки **«💬 Тренер: …»**. Якщо їх немає — перевір, що `AI_ENABLED=true` і ключ правильний.

2. **Логи в Supabase:**  
   У Supabase → **Table Editor** → таблиця **ai_generated_content**.  
   Після генерації плану або після нагадувань/завершення тренування тут мають з’являтися нові рядки (content_type: `plan_comment`, `reminder` або `failure_analysis`). Це означає, що виклики AI відбулися.

3. **Помилки:**  
   Якщо щось не так (ключ невірний, немає грошей на балансі), у **Railway** у вкладці **Deployments** можна відкрити останній деплой і подивитися **логи** (View logs). Там буде видно повідомлення на кшталт `aiClient.chatCompletion` або `planComments` — це допоможе зрозуміти, де саме помилка.

## Якщо щось не працює

- **Ключ не приймається:** переконайся, що вставила повний рядок без пробілів на початку/в кінці, без лапок у значенні змінної.  
- **«Insufficient quota» або подібне:** на OpenAI закінчився баланс — поповни рахунок в **Billing** на platform.openai.com.  
- **Коментарі не з’являються:** (1) Переконайся, що дивишся **новий** план, створений саме через «Новий план» → «Авто-підбір» → «Генерувати» після підключення AI. (2) Перевір у Railway, що `AI_ENABLED` саме `true` (малими літерами). (3) Подивися логи деплою в Railway — чи немає помилок після виклику OpenAI.

Якщо напишеш, на якому кроці зупинилася (наприклад, «не знайду API keys на OpenAI» або «не бачу Variables в Railway»), можу розписати саме цей крок ще детальніше.
