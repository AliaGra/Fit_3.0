# Документація адміністративного бота — огляд для оцінки

**Код:** `lib/adminBot.js`, `lib/adminVenues.js`, `lib/adminHelpers.js`, `lib/adminTelegram.js`  
**Вхід:** окремий webhook `POST /admin_webhook` (`index.js`), токен `ADMIN_BOT_TOKEN`.  
**Безпека:** відповідає **лише** `ADMIN_CHAT_ID`.

---

## 1. Призначення

Окремий Telegram-бот для операційного керування платформою без доступу до коду/БД напряму з UI:
користувачі, інвайти, модерація закладів і відгуків, заявки «я власник», аудит, флаги циклу вправ.

---

## 2. Основні розділи меню

| Розділ | Можливості |
|--------|------------|
| Статистика | Зведення по користувачах / активності (ADM_STATS) |
| Користувачі | Список з пагінацією, пошук, картка користувача |
| Картка user | Блок/розблок, видалення (з підтвердженням + cascade), типи тренувань тренера, зняття власника |
| Інвайти | Список `INVITE_*`, видалення одного / всіх |
| Заклади | Модерація pending (`adminVenues`) — approve / reject / delete |
| Групові заняття | Черга `pending` / `archive_pending` / `restore_pending` (картка клубу; підтвердження з власником) |
| Відгуки | Черга `pending` → схвалити / відхилити |
| Заявки власника | Approve / reject заявок тренера на venue_owner |
| Цикл вправ | Аудит флагів exercise↔cycle (списки, mark reviewed) |
| Лог | Перегляд `admin_log` |

---

## 3. Технічні акценти

- Cascade-видалення користувача чистить повʼязані персональні таблиці (див. WORKLOG / supabase helpers).  
- Модерація відгуків впливає на публічну картку (середній бал лише published).  
- Venue moderation: каталог користувачів бачить лише `approved`.  
- Group class moderation: publish / archive / restore через статуси в `coach_group_classes` (не миттєвий архів у прод-каталозі).  
- Окремий Telegram-клієнт (`adminTelegram`) — ізоляція від основного бота.

---

## 4. Змінні середовища

- `ADMIN_BOT_TOKEN`  
- `ADMIN_CHAT_ID`  
- (+ спільні `SUPABASE_*`)

---

## 5. Для оцінки адміністративної частини

- Повноцінний **операційний контур** (не «заглушка»): CRUD-ризикові дії з підтвердженнями.  
- Модерація UGC (відгуки) і контенту каталогу (заклади).  
- Аудит і підтримка цілісності (інвайти, cascade delete, cycle flags).  
- Обсяг: окремий бот + кілька модулів (~1k+ рядків логіки адмінки разом із venues).
