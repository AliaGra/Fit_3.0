# Структура проєкту / модулі — огляд для оцінки

**Точка входу:** `index.js` — HTTP-сервер: webhook Telegram, admin/help webhooks, cron endpoints.  
**Робочий runtime:** `lib/*.js` (~77 модулів) + `lib/ai/*` (~11 файлів).  
**Правила розробки:** `.cursorrules`.

## 4. Для оцінки обсягу реалізації

- Повноцінний **монолітний Node-бот** з чітким поділом відповідальності по файлах.  
- Великий шар UI-колбеків і FSM (див. також `CALLBACK_FSM_MODULE_MATRIX.md`).  
- Окремі боти: **main**, **admin**, **help** — розширює контур підтримки/модерації.  
- Документація та міграції в репо співрозмірні з кодом (зрілий інженерний процес).
