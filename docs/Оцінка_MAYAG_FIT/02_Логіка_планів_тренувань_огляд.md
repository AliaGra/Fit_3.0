# Логіка складання планів тренувань — огляд для оцінки

**Повний канон:** `Логіка складання плану тренувань.md` (+ `Логіка_складання_плану_тренувань_v1_1.md`).  
**Код:** `lib/planGenerator.js`, `lib/medicalFilter.js`, `lib/medicalProfile.js`, `lib/trainingPlan.js`, `lib/training.js`.

---

## 1. Мета алгоритму

Побудувати **індивідуальний** план для учня з урахуванням:
цілі, рівня, днів на тиждень, зон акценту/уникнення, медичних станів (severity + severity), бібліотеки вправ.

Підбір вправ, sets/reps/rest — **детерміновані**. AI лише додає текстові коментарі (опційно).

---

## 2. Конвеєр (високий рівень)

```
Профіль учня + медичні стани
        ↓
filterExerciseForUser (BLOCKED / ALLOWED_WITH_MOD / SAFE / NEUTRAL)
        ↓
generateTrainingPlan (рівень, спліт, дні, підбір вправ)
        ↓
[опційно] AI plan comments → notes
        ↓
Збереження training_plans + training_plan_exercises
        ↓
Активація (valid_until ≈ +N тижнів) → виконання учнем / з тренером
        ↓
Прогресія (+кг) / деавтоматизація (−10%, notify тренеру)
        ↓
Cron ревізії плану
```

---

## 3. Медична фільтрація (складність)

| Статус | Значення |
|--------|----------|
| BLOCKED | Вправу не брати в план |
| ALLOWED_WITH_MOD | Можна з модифікацією / notes |
| SAFE | Підходить |
| NEUTRAL | Немає явного конфлікту |

Дані: `user_medical_conditions` + поля `exercise_library` (contraindications / limitations / safe_for / modifications).  
Розшифровка кодів MC у картці вправи: `lib/medicalDecode.js`.

---

## 4. Генерація та UI

- **Авто-підбір:** `generateTrainingPlan` — спліт за днями, кількість вправ, sets/reps/rest за рівнем/ціллю.  
- **Вручну:** тренер додає вправи; тип виконання SET або SINGLE.  
- UI: «Програма тренувань» → список / новий / активувати / видалити (`lib/trainingPlan.js`).  
- Виконання: учень або тренер (день плану / вільне тренування) — `lib/training.js`.

---

## 5. Для оцінки складності алгоритмів

- Комбінаторика: фільтр бібліотеки × медичні коди × спліт × рівень × зони.  
- Стан машини довгого UI (багато callback-префіксів PLAN_*).  
- Пост-генераційні правила: ревізія, прогресія, деавтоматизація, AI-коментарі як окремий шар.
