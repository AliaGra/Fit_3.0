# Опис AI-функцій MAYAG FIT — огляд для оцінки

**Канон принципу:** `Принцип_роботи_AI_в_боті.md`  
**План/онбординг:** `AI_Integration_FIT3_Implementation_Plan.md`, `Підключення_AI_покроково.md`  
**Код:** `lib/ai/*`  
**Збереження:** таблиця `ai_generated_content` (міграція `supabase_migration_ai_content.sql`)

---

## 1. Принцип інтеграції

- AI **опційний**: `AI_ENABLED=true` + `OPENAI_API_KEY`.  
- Модель за замовчуванням: `gpt-4o-mini` (`AI_MODEL`, `AI_MAX_TOKENS`, `AI_TIMEOUT_MS`).  
- При вимкненні / помилці / невалідній відповіді — **fallback** без падіння сценарію.  
- **Детерміноване ядро** (підбір вправ, sets/reps, медичний фільтр, розклад) **не** замінюється AI.  
- Відповіді валідуються (`aiValidator.js`); промпти — `aiPrompts.js`; клієнт — `aiClient.js`.

---

## 2. Реалізовані AI-сценарії

| Сценарій | Модуль | Коли | Результат |
|----------|--------|------|-----------|
| Коментарі до плану | `planComments.js` | Після авто-генерації плану | `notes` до вправ + day_summary |
| Розумне нагадування | `smartReminder.js` | Cron `/cron/reminders` (~2h) | Персональний текст учню |
| Аналіз невиконання | `failureAnalysis.js` | Після завершення плану-тренування (<80% сетів) | Повідомлення учню ± тренеру |
| AI-аналіз тіла | `bodyAnalysis.js` | Реєстрація / оновлення замірів / on-demand | Збережений текст аналізу |
| Цілі vs поточний стан | `goalsVsCurrent.js` | Переказ результатів `analyzeGoalsVsCurrentState` | Текст для учня |
| Історія тренувань | `historyAnalysis.js` | Модуль історії (AI-блок) | Аналітичний текст |
| Прогресивний план | `progressivePlanAI.js` | Повʼязано з progressive plan | Допоміжний AI-контент |
| Тижневий дайджест | `weeklyDigest.js` + cron | `/cron/weekly-digest` | Дайджест тренеру |

---

## 3. Архітектура шару AI

```
Feature code (trainingPlan / reminders / profile / …)
        ↓
lib/ai/<feature>.js  →  build prompt (aiPrompts)
        ↓
aiClient.chatCompletion / safeCall
        ↓
aiValidator
        ↓
UI send + insert ai_generated_content (tokens/cost/type)
```

---

## 4. Для оцінки AI-інтеграцій

- Не «чат GPT у боті», а **вбудовані точки** з валідацією і audit trail.  
- Чітке розділення: алгоритми тренувань / медицини — rule-based; AI — NLP/копірайт і мʼяка аналітика.  
- Керування вартістю: ліміти токенів, timeout, можливість повного вимкнення.  
- Кілька незалежних content_type у БД для аналітики використання.

---

## 5. Не AI (важливо для оцінки)

Медична фільтрація, генерація спліту, прогресія ваги, розклад, абонементи, розсилка, ДН-cron — **без OpenAI**.
