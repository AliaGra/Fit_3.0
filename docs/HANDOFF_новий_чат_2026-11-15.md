## 1. Що вже зроблено (коміт `8c429c7` на `main`)

### Публічна картка тренера
- Типи: `personal` / `split` / `trio` / `group` (+ послуги online / programs / nutrition).
- Instagram і документи **завжди** на картці (або «посилання/документів ще немає»).
- Текст: «Щоб тренуватися або задати питання тренеру — напиши йому.»
- Кнопка **«Написати / задати питання тренеру»** — лише якщо глядач **не клієнт** і не сам тренер.

### Звернення (`lib/coachInquiry.js`)
- Меню: клуб (групове → список / індив. / спліт / тріо) → онлайн → програма → харчування → своє питання.
- Показувати лише увімкнені в профілі тренера формати/послуги.
- Ліміт: нове звернення **лише якщо немає** статусу `open` до цього тренера.
- Автовідповідь (стать з профілю; нейтрально якщо стать не вказана); вимикач у **Публічні дані**.
- Тренеру: повідомлення + **Відповісти** (префікс `Вітаю, {імʼя}, ви запитували — {тема},`) + **Профіль клієнта**.
- Cron: `GET /cron/coach-inquiry-reminders` — нагадування через **8 год**, якщо ще `open`.

### Міграція (обовʼязково в Supabase, якщо ще не ганяли)
Файл: `supabase_migration_coach_inquiries.sql`  
- таблиця `coach_inquiries`  
- колонка `users.coach_inquiry_auto_reply` (default `true`)

### Cron на Railway / cron-job.org
`/cron/coach-inquiry-reminders?secret=<REMINDER_CRON_SECRET>`  
рекомендовано **щогодини** (у коді — нагадування після **8 год** без відповіді, не плутати з інтервалом cron).

## 4. Що перевірити вручну після деплою

1. Міграція застосована в Supabase.  
2. Картка тренера з клубу — усі типи, IG, документи.  
3. Не-клієнт → «Написати…» → тема → тренер отримує повідомлення + автовідповідь.  
4. Відповідь тренера з префіксом «Вітаю…».  
5. Друге звернення блокується, поки перше `open`.  
6. Cron 8 год (можна тимчасово зменшити поріг у коді для тесту).

## 6. Вікно вводу в Cursor (якщо знову зникне)

Спробувати по черзі:
1. `Ctrl+L` / `Cmd+L` — новий Agent-чат (поле вводу зазвичай є).  
2. Закрити/відкрити панель Chat (View → Chat / Agent).  
3. `Ctrl+Shift+P` → «View: Reset View Locations» або «Developer: Reload Window».  
4. Якщо чат «зламаний» — новий чат і цей handoff-файл.

**Старт у новому чаті:** відкрий цей файл і скажи агенту:  
«Прочитай `docs/HANDOFF_новий_чат_2026-11-15.md` і `Зміни_логіки_та_функціоналу.md` (блок 14.11) — продовжуємо звідти.»
