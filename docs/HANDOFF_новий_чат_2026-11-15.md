## 4. Що перевірити вручну після деплою

1. Міграція застосована в Supabase.  
2. Картка тренера з клубу — усі типи, IG, документи.  
3. Не-клієнт → «Написати…» → тема → тренер отримує повідомлення + автовідповідь.  
4. Відповідь тренера: «Вітаю, {імʼя}.» + текст; опційно пробний запис.  
5. Друге звернення блокується, поки перше `open`.  
6. Cron 8 год (можна тимчасово зменшити поріг у коді для тесту).
7. Адмін: видалити тестового учня → у Supabase немає `users`, `coach_inquiries` від нього, trial booking; слот тренера без `student_id`.

## 6. Вікно вводу в Cursor (якщо знову зникне)

Спробувати по черзі:
1. `Ctrl+L` / `Cmd+L` — новий Agent-чат (поле вводу зазвичай є).  
2. Закрити/відкрити панель Chat (View → Chat / Agent).  
3. `Ctrl+Shift+P` → «View: Reset View Locations» або «Developer: Reload Window».  
4. Якщо чат «зламаний» — новий чат і цей handoff-файл.

**Старт у новому чаті:** відкрий цей файл і скажи агенту:
