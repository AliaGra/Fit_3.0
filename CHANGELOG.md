# Changelog (FIT 3.0)

Фіксуємо зміни функціоналу в короткому форматі (що змінилось для користувача).

## Unreleased

- **Локація користувача/закладу + сповіщення про новий заклад (2026-05-11, `1be26af`)**:
  - Додано міграцію `supabase_migration_users_venues_location_notify.sql`: `users.oblast`, `users.district`, `venues.district`.
  - Після додавання нового закладу адміном запускається розсилка в основний бот (`lib/venueNewNotify.js`) з кнопкою відкриття картки закладу.
  - Таргетинг розсилки: `oblast + city`, і якщо в закладі задано район — додаткове звуження за `district` (без фільтра за роллю; виключаються `INVITE_%` та `is_blocked`).
  - У реєстрації та в редагуванні міста профілю додано опційний крок введення району.
  - В адмін-боті для закладу додано поле «Район» (створення/редагування/превʼю), у картці закладу в основному боті район також відображається.

- **Клуби, студії (довідник закладів)**:
  - Головне меню: **«🏢 Клуби, студії»** — пошук поруч (геолокація + радіус) або за областю/містом/назвою; фільтр за типом організації з довідника.
  - Після вибору міста в **реєстрації** — пропозиція знайти заклад у місті або **«пізніше»**; збереження обраного закладу в профілі.
  - **Профіль тренера → «Де треную (заклади)»** — прив’язка закладу з каталогу.
  - **Адмін-бот** (`/admin_webhook`): меню **«Заклади»** — додавання закладу (обов’язкова геолокація з Telegram), тип організації, соцмережі.
  - **Адмін-бот (оновлення):** групові заняття задаються **лише вибором з довідника** `venue_directory_codes` (кнопки, пагінація, мультивибір) — без ручного вводу кодів.
  - SQL у репозиторії: `supabase_migration_venues.sql`, `supabase_migration_venues_seed_directory.sql` (потрібно виконати в Supabase).
  - **Оновлення (2026-04):** хаб «Клуби» з блоком **«Мої заклади»**, кнопка **«Пошук нового закладу»**, deep link **`venue_<id>`**; на картці закладу — **«Тренери закладу»** з кнопками переходу в публічну картку тренера (`PVCH`), deep link **`pvch_<chatId>`**; текстовий пошук без повторного вводу міста, якщо дані вже в профілі; **адмін:** картка закладу зі списку (години, розклад групових, amenities, телефон, ціни-довідник), превʼю та редагування перед/після збереження; міграції див. `WORKLOG.md` / `VENUES_DIRECTORY_IMPLEMENTATION_PLAN.md`.
- **Документи тренера**:
  - Під час реєстрації тренера можна завантажити документи про освіту у сфері фітнесу (фото/файл).
  - Учень бачить документи у `Мій тренер`.
  - Тренер може переглядати/додавати/видаляти документи у `Профіль → Мої документи`.
- **Профіль → Оновити заміри**:
  - Додано розширені підказки для замірів (у т.ч. талія/ягодиці/шия/запʼястя/плечі).
  - Перейменовано замір “рука” на **біцепс (розслаблено)**.
  - Додано новий замір: **біцепс (напруга)**.
- **Help-bot (FitHad_Help)**: після видачі інвайт-коду користувачу додано вибір ручного виходу `🏠 Гл.меню` (без закриття звернення) або `✅ Завершити діалог` (закрити звернення).
- **Тренер → Розклад → Мій розклад → Вільні слоти**: за замовчуванням показуються вільні слоти **на 3 дні** від сьогодні; додано кнопку **«Інші вільні слоти»** для перегляду решти вільних слотів у вікні 21 день.
- **Тренер → Розклад → Календар → обрана дата**:
  - Додано підказки про дії **❌ скасувати** та **🔄 перенести** (з підтвердженням учнем); кнопку **✔️ (відмітити тренування)** прибрано з цього екрана.
  - Підказка для “вільного” слота у стилі кнопки: **👤 Вільний**.
  - Для зайнятого (`BOOKED`) слота: кнопки в один ряд **[час + ПІБ] [❌] [🔄]**, де перша кнопка відкриває read-only інформацію по слоту.
  - Для слота-перерви (`RESERVED`): дія **«Відкрити слот»** перейменована на **«Відмінити»** (скасувати перерву).
- **Тренер → Розклад**:
  - Меню перебудовано: **«📆 Календар (21 день)»** винесено у верхнє меню; підменю **«Мій розклад»** перейменовано на **«🕒 Слоти - праця с ними»**.
  - Створено підменю **«🍔 Мої перерви \ відпустки»** (перерви/відпустки зібрані в одному місці).
  - Додано підказку, як записати учня на тренування (через **«Мої учні»** або через **«Календар»**).
- **Тренер → Розклад → Відмітити тренування**: оновлено тексти підказок (про автопозначення виконаного тренування при записі через меню «Тренування», про звіт/доходи/статистику), використано префікс **💰💲**, звертання у форматі “ти”.
- **Відпустки тренера**: додано захист від запису/переносу на слоти у дні відпустки (для тренера та учня); календар переносу не пропонує дні відпустки.
- **Реєстрація (закрите бета)**:
  - Кнопка **«✅ Нова реєстрація»** показує повідомлення, що доступ лише за інвайт‑кодом, та посилання на support-бот.
  - Після введення `INVITE_XXXX` додано гейт з офертою: **«📋 Читати угоду»** → показ тексту; **«✅ Приймаю умови»** → активація інвайту; **«❌ Відмовитись»** → доступ не активується.
- **Головне меню (тренер/учень)**: додано пункт **«Зв’язок з розробником»** (написати розробнику / читати оферту).
