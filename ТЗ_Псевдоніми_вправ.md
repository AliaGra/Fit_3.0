## 1. МЕТА ФУНКЦІОНАЛА

Дозволити тренеру та учню зберігати **власні назви (псевдоніми)** для вправ з бібліотеки `exercise_library`. Псевдонім — це будь-яке слово або фраза, яку користувач звик вживати для конкретної вправи: сленг, скорочення, назва тренажера, термін зі своєї школи тренувань.

**Проблема яку вирішує:** Пошук вправи за офіційною назвою незручний — у різних тренерів і залів різна термінологія. "Блок зверху", "lat pulldown", "тяга до грудей" — все це одна і та ж вправа.

---

## 2. РОЛІ ТА РІВНІ ПСЕВДОНІМІВ

| Рівень | Хто створює | Кому видно | Пріоритет при пошуку |
|--------|------------|-----------|----------------------|
| **Personal** | Будь-який користувач (тренер або учень) | Тільки собі | 1-й (найвищий) |
| **Coach-shared** | Тренер | Тренер + всі його активні учні | 2-й |

**Правила:**
- Тренер, створюючи псевдонім, обирає scope: `personal` або `coach_shared`
- Учень може створювати тільки `personal` псевдоніми
- Якщо тренер має `coach_shared` псевдонім і учень має свій `personal` для тієї ж вправи — при пошуку учня першим іде `personal`
- Учень **не бачить** інтерфейс управління `coach_shared` — він просто "знаходить" вправу по цій назві як по звичайній

## 3. СХЕМА БАЗИ ДАНИХ

### 3.1 Нова таблиця `exercise_aliases`

```sql
CREATE TABLE exercise_aliases (
  id          UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id     BIGINT NOT NULL,          -- users.chat_id власника псевдоніма
  exercise_id INT NOT NULL,             -- exercise_library.id
  alias       TEXT NOT NULL,            -- текст псевдоніма
  scope       TEXT NOT NULL DEFAULT 'personal',  -- 'personal' | 'coach_shared'
  created_at  TIMESTAMPTZ DEFAULT NOW(),

  CONSTRAINT fk_exercise FOREIGN KEY (exercise_id) REFERENCES exercise_library(id) ON DELETE CASCADE,
  CONSTRAINT uq_user_alias UNIQUE (user_id, alias)  -- один псевдонім = одна вправа для юзера
);

CREATE INDEX idx_aliases_user_id ON exercise_aliases(user_id);
CREATE INDEX idx_aliases_exercise_id ON exercise_aliases(exercise_id);
CREATE INDEX idx_aliases_scope ON exercise_aliases(user_id, scope);
```

**Важливо:** `alias` зберігається в нижньому регістрі (normalization при INSERT).

### 6.1 Функції модуля

```javascript
// Додати псевдонім
async addAlias(userId, exerciseId, aliasText, scope)
// Повертає: { success, alias_id, error? }
// Нормалізація: aliasText.trim().toLowerCase()
// Валідація: довжина 2–40 символів, не порожній
// При дублікаті (uq_user_alias) — повернути { success: false, error: 'DUPLICATE' }

// Видалити псевдонім
async deleteAlias(aliasId, userId)
// Повертає: { success, error? }
// Перевірка: alias.user_id === userId (захист від видалення чужих)

// Отримати псевдоніми користувача для конкретної вправи
async getAliasesForExercise(userId, exerciseId)
// Повертає: [{ id, alias, scope, created_at }, ...]

// Пошук вправ по псевдоніму (основна функція пошуку)
async searchByAlias(query, userId, coachId)
// Параметри:
//   query    — рядок запиту (нормалізований: trim().toLowerCase())
//   userId   — chat_id поточного користувача
//   coachId  — users.coach_id поточного користувача (може бути null)
// Логіка:
//   1. Шукати точний збіг у personal псевдонімах userId
//   2. Якщо coachId != null — шукати у coach_shared псевдонімах coachId
//   3. Об'єднати, видалити дублікати по exercise_id, сортувати: personal спочатку
// Повертає: [{ exercise_id, alias, scope, ...exercise_library fields }, ...]

// Отримати всі псевдоніми користувача (для меню управління)
async getAllAliasesByUser(userId)
// Повертає: [{ id, alias, scope, exercise_id, name_ua }, ...]
// Сортування: за назвою вправи (name_ua)
```

## 8. ОБРОБНИК CALLBACK В `lib/alias.js`

### `handleCallback(chatId, action, params, callbackQueryId)`

| action | Логіка |
|--------|--------|
| `ALIAS_ADD` | Отримати exercise_id з params. Якщо роль = coach → показати вибір scope (2 кнопки). Якщо роль = student → одразу встановити scope='personal', перейти до введення тексту. FSM: `alias_input_text`, зберегти в state `{ exercise_id, scope }` |
| `ALIAS_SCOPE` | Зберегти scope в state, перейти до введення тексту. FSM: `alias_input_text` |
| `ALIAS_LIST` | Показати список псевдонімів користувача для цієї вправи. Кожен запис — кнопка `[🗑 alias_text]` → `ALIAS_DEL:{alias_id}`. Кнопка `[Назад]` → `ALIAS_BACK:{exercise_id}` |
| `ALIAS_DEL` | Показати підтвердження: "Видалити псевдонім 'блок зверху'?" `[Так, видалити]` → `ALIAS_DEL_CONFIRM:{alias_id}`. `[Скасувати]` → `ALIAS_LIST:{exercise_id}` |
| `ALIAS_DEL_CONFIRM` | Викликати `deleteAlias`. Показати повідомлення "✅ Псевдонім видалено". Повернутись до `ALIAS_LIST:{exercise_id}` |
| `ALIAS_BACK` | Показати картку вправи через `library.showExerciseDetail(chatId, exercise_id)` |

### Обробник текстового вводу (FSM стан `alias_input_text`)

```
Отримати з state: { exercise_id, scope }
Нормалізувати: input.trim().toLowerCase()
Валідація:
  - довжина < 2 або > 40 → "Псевдонім має бути від 2 до 40 символів"
  - порожній → "Введіть текст"
Виклик: addAlias(userId, exercise_id, normalizedAlias, scope)
  - success: "✅ Псевдонім '[alias]' збережено!" → показати картку вправи
  - DUPLICATE: "⚠️ Такий псевдонім у вас вже є" → залишитись у стані, запропонувати інший
Очистити FSM state
```

### Де зараз знаходиться пошук

Файл: `lib/training.js`  
FSM стан: `training_search_name_input`

### Що змінити

В місці де обробляється FSM стан `training_search_name_input`:

```javascript
// 1. Отримати дані поточного користувача (для coachId)
const user = await supabase.getUserByChatId(chatId);

// 2. Пошук по псевдонімах (новий)
const aliasResults = await alias.searchByAlias(query, chatId, user.coach_id);

// 3. Пошук по назвах (існуючий)
const nameResults = await supabase.searchExercises(query);

// 4. Об'єднання: псевдоніми спочатку, без дублікатів по exercise_id
const aliasIds = new Set(aliasResults.map(r => r.exercise_id));
const combined = [
  ...aliasResults,
  ...nameResults.filter(r => !aliasIds.has(r.id))
];

// 5. Якщо combined порожній — повідомлення "Нічого не знайдено"
// 6. Якщо 1 результат — одразу відкрити картку вправи
// 7. Якщо кілька — показати список кнопками (псевдоніми з 🏷)
```

## 11. ОБМЕЖЕННЯ ТА ВАЛІДАЦІЯ

| Параметр | Правило |
|----------|---------|
| Довжина псевдоніма | від 2 до 40 символів |
| Максимум псевдонімів на вправу | 10 на одного користувача |
| Максимум псевдонімів всього | 200 на одного користувача |
| Унікальність | один псевдонім не може посилатись на дві різні вправи у одного юзера (constraint `uq_user_alias`) |
| Нормалізація | завжди `trim().toLowerCase()` при збереженні і при пошуку |
| Спецсимволи | дозволені (щоб можна було писати "lat/pulldown", "тяга 45°") |

## 12. МІГРАЦІЯ SUPABASE

Файл: `migrations/add_exercise_aliases.sql`

```sql
-- Створення таблиці
CREATE TABLE IF NOT EXISTS exercise_aliases (
  id          UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id     BIGINT NOT NULL,
  exercise_id INT NOT NULL,
  alias       TEXT NOT NULL,
  scope       TEXT NOT NULL DEFAULT 'personal'
                CHECK (scope IN ('personal', 'coach_shared')),
  created_at  TIMESTAMPTZ DEFAULT NOW(),

  CONSTRAINT fk_alias_exercise
    FOREIGN KEY (exercise_id)
    REFERENCES exercise_library(id)
    ON DELETE CASCADE,

  CONSTRAINT uq_user_alias
    UNIQUE (user_id, alias)
);

-- Індекси
CREATE INDEX IF NOT EXISTS idx_aliases_user_id
  ON exercise_aliases(user_id);

CREATE INDEX IF NOT EXISTS idx_aliases_exercise_id
  ON exercise_aliases(exercise_id);

CREATE INDEX IF NOT EXISTS idx_aliases_scope_user
  ON exercise_aliases(user_id, scope);

-- Індекс для повнотекстового пошуку по alias (опційно)
CREATE INDEX IF NOT EXISTS idx_aliases_alias_text
  ON exercise_aliases USING gin(to_tsvector('simple', alias));
```

## 15. ТЕСТОВІ СЦЕНАРІЇ

### Тренер

| Сценарій | Очікуваний результат |
|----------|----------------------|
| Відкрити картку вправи | Бачить кнопки "🏷 Мої псевдоніми" і "➕ Додати псевдонім" |
| Натиснути "➕ Додати псевдонім" | Отримує вибір scope (особистий / для учнів) |
| Обрати "для учнів", ввести "блок зверху" | Псевдонім збережено зі scope=coach_shared |
| Обрати "тільки для мене", ввести "lat pulldown" | Псевдонім збережено зі scope=personal |
| Шукати "блок зверху" | Вправа знайдена першою з позначкою 🏷 |
| Спробувати ввести "блок зверху" ще раз | Помилка "Такий псевдонім у вас вже є" |
| Переглянути псевдоніми → видалити один | Псевдонім видалено, список оновлено |

### Учень (тренер встановив coach_shared)

| Сценарій | Очікуваний результат |
|----------|----------------------|
| Шукати "блок зверху" | Вправа знайдена (через coach_shared тренера) з позначкою 🏷 |
| Відкрити картку вправи | Бачить кнопки псевдонімів (але не бачить що це coach_shared) |

| Шукати "тяга згори" | Знаходить по personal псевдоніму |

### Учень без тренера

| Сценарій | Очікуваний результат |
|----------|----------------------|
| Шукати будь-що | Пошук тільки по personal псевдонімах + назвах |
| Додати псевдонім | Зберігається одразу як personal без вибору scope |
