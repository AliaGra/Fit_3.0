## Формат callback_data

**ВАЖЛИВО:** У всіх сценаріях нижче використовується формат з підкресленням для наочності прикладів:
```
VIEW_STUDENT_123456789
SCH_C_REQ_evt_def456
SCH_CONF_7
```

**ФАКТИЧНА РЕАЛІЗАЦІЯ В КОДІ:**
Замінити підкреслення між префіксом та параметром на двокрапку (`:`):
```javascript
// Приклад сценарію (наочність):
callback_data: "VIEW_STUDENT_123456789"

// Реальний код:
callback_data: "VIEW_STUDENT:123456789"
```

**Формат парсингу в Router:**
```javascript
const [action, ...params] = callbackData.split(':');
// action = "VIEW_STUDENT"
// params[0] = "123456789"
```

**Причина:** Двокрапка забезпечує чистий та однозначний парсинг без необхідності знати структуру префіксу.
