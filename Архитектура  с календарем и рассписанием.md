Поточна ситуація:

🎯 ВИКОРИСТАННЯ

Для розробників:



Перевіряти цю карту перед додаванням require() або виклику функції з іншого модуля

Якщо потрібен виклик з іншого шару - рефакторити архітектуру

Використовувати Audit.checkDependencies() перед commit



Для code review:



Перевіряти що нові виклики відповідають матриці

Шукати потенційні циклічні залежності

Переконатись що Handler модулі ізольовані



Для рефакторингу:



Якщо виникла потреба в забороненому виклику - винести логіку в Business/Infrastructure шар

Розділяти великі модулі на менші з чіткою відповідальністю
