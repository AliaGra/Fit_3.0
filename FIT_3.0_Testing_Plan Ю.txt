FIT 3.0 — План тестирования с реальными пользователями
Срок: 1 месяц (закрытое бета-тестирование)  
Цель: проверить основные сценарии по всем ролям до открытого запуска  
Роли: Администратор · Владелец заведения · Тренер · Ученик с тренером · Пользователь-одиночка
Обозначения критичности:
🔴 КРИТИЧНО — блокирует работу системы, тестируется в первую очередь
🟡 ВАЖНО — ключевой пользовательский сценарий, влияет на опыт
🟢 ЖЕЛАТЕЛЬНО — UX-детали, некритичные функции
---
Этап 1 — Первые шаги (дни 1–7)
> Задача: убедиться, что регистрация, базовая навигация и запись на тренировку работают без критических сбоев.
1. Администратор
[ ] 🔴 Войти в админ-бот, проверить главное меню
[ ] 🔴 Создать тестовое заведение (обязательная геолокация, тип организации)
[ ] 🔴 Создать инвайт-код для тренера
[ ] 🔴 Создать инвайт-код для ученика
[ ] 🔴 Проверить раздел «👥 Пользователи» — нет дублей, нет INVITE_* строк
[ ] 🟡 Проверить раздел «🔑 Инвайты» — неактивированные коды видны
[ ] 🔴 Назначить владельца заведения через ADM_VOWN
---
2. Владелец заведения
[ ] 🔴 Зарегистрироваться как «Владелец заведения» по инвайт-коду
[ ] 🔴 Принять условия оферты при активации кода
[ ] 🔴 Открыть главное меню: убедиться что есть «Мой заклад», «Тренеры заведения», «Клубы, студии», «Связь с разработчиком»
[ ] 🟡 Открыть «Мой заклад» — публичная карточка отображается корректно (адрес, тип)
[ ] 🟡 Найти своё заведение через «Клубы, студии» — поиск по названию (мин. 3 буквы)
[ ] 🟢 Прочитать «📜 Условия использования»
---
3. Тренер
[ ] 🔴 Зарегистрироваться как тренер (роль «Тренер» — первая кнопка)
[ ] 🔴 Пройти полную анкету: имя, фамилия, пол, дата рождения, город, цель
[ ] 🟢 (Опционально) загрузить документ об образовании (фото или файл)
[ ] 🟡 Открыть главное меню тренера, проверить все пункты
[ ] 🔴 Добавить тестового ученика: «Мои ученики» → «Добавить ученика» → получить INVITE_XXXX
[ ] 🔴 Убедиться что инвайт-код пришёл отдельным сообщением
[ ] 🔴 Создать слоты в расписании на ближайшие 3 дня
[ ] 🟡 Открыть «Календарь (21 день)» — проверить легенду (🟢 сегодня, 🟡 выходной, ⬜ без слотов)
[ ] 🔴 Записать ученика на тренировку через «Мои ученики» → «Записать»
[ ] 🔴 Подтвердить запрос ученика на тренировку (REQUESTED → BOOKED)
---
4. Ученик с тренером
[ ] 🔴 Ввести инвайт-код от тренера в боте
[ ] 🔴 Прочитать оферту («📋 Читать соглашение»), нажать «✅ Принимаю условия»
[ ] 🔴 Пройти регистрацию: имя, фамилия, пол, дата рождения, город
[ ] 🔴 Убедиться что в профиле указан тренер (coach_id заполнен)
[ ] 🔴 Открыть «🖋️ Запись на тренировку» → выбрать свободный слот в календаре
[ ] 🔴 Убедиться что после запроса меню заблокировано до подтверждения тренером
[ ] 🔴 Получить подтверждение от тренера → статус BOOKED
[ ] 🟡 Попробовать перенести тренировку: запросить перенос, тренер подтверждает
[ ] 🟡 Проверить «Мой тренер» — видна карточка тренера и его документы (если загружены)
[ ] 🟢 Прочитать «📜 Условия использования»
---
5. Пользователь-одиночка (без тренера)
[ ] 🔴 Проверить что кнопка «✅ Новая регистрация» заблокирована в закрытой бете — показывается сообщение о закрытом доступе и ссылка на support
[ ] 🔴 Активировать универсальный инвайт, пройти полную регистрацию
[ ] 🟡 Открыть главное меню ученика, проверить все пункты
[ ] 🟡 Попробовать раздел «🏢 Клубы, студии» — поиск заведений по городу
[ ] 🟢 Прочитать «📜 Условия использования»
[ ] 🟢 Открыть «💡 Подсказки» — убедиться в наличии solo-набора подсказок
[ ] 🟡 Попробовать «Моё тренування» без активного плана — проверить что бот не падает, показывает корректное сообщение
---
Этап 2 — Тренировочный процесс (дни 8–14)
> Задача: проверить создание планов, выполнение тренировок и работу автоматики прогрессии.
1. Администратор
[ ] 🟡 Проверить статистику после регистрации тестовых пользователей — числа корректны, без дублей
[ ] 🟡 Убедиться что разосланы уведомления о новом заведении (только пользователи из того же города)
[ ] 🟡 Проверить таблицу `ai\_generated\_content` в Supabase — появились записи после генерации планов
---
2. Владелец заведения
[ ] 🟡 Открыть «Тренеры заведения» — список отображается, кнопки перехода в карточку тренера (PVCH) работают
[ ] 🟡 Отредактировать контакты заведения (телефон / Instagram)
[ ] 🟡 Задать групповые занятия через справочник (не ручной ввод) — мультивыбор кнопками
[ ] 🟡 Убедиться что обновлённая карточка заведения отображается корректно в «Мой заклад»
---
3. Тренер
[ ] 🔴 Открыть «Программа тренировок» → «Новый план» → «Авто-подбор» → «Генерировать»
[ ] 🔴 Проверить план: упражнения подобраны с учётом цели и уровня ученика, медицинские фильтры применены
[ ] 🟡 Если AI включён: под упражнениями отображаются комментарии «💬 Тренер»
[ ] 🔴 Активировать план для ученика
[ ] 🟡 Создать ручной план: добавить упражнения из каталога и из «⭐ Мои упражнения»
[ ] 🟡 Добавить собственное упражнение в «Мои упражнения» (категория, название)
[ ] 🔴 Задать стоимость тренировок для ученика («💰 Стоимость тренировок»)
[ ] 🔴 Провести тренировку с учеником: «Тренировки учеников» → тип (Персональная/Сплит/Трио) → выбрать ученика → упражнения → завершить
[ ] 🔴 После завершения: проверить что в слоте появился price_charged и статус COMPLETED
[ ] 🔴 Открыть «Отчёты» → «Сумма доходов» — тренировка отображается корректно
---
4. Ученик с тренером
[ ] 🔴 Открыть «Моє тренування» — предложен активный план, выбрать день
[ ] 🔴 Пройти тренировку по плану: ввести вес и повторы для каждого упражнения
[ ] 🔴 Завершить тренировку — данные сохранены в bot_training_data
[ ] 🟡 После 1–2 выполненных тренировок: проверить автопрогрессию (target_weight +2.5/1.25 кг)
[ ] 🟡 Намеренно не выполнить 80% подходов в одной тренировке — бот не падает, данные сохранены
[ ] 🟡 Обновить замеры тела («Профиль» → «Обновить замеры»): все поля с подсказками (талия, ягодицы, шея, запястье, плечи, бицепс расслаблен / напряжён)
[ ] 🟡 Проверить что «🤖 AI-аналитика» в главном меню показывает текст анализа тела
---
5. Пользователь-одиночка (без тренера)
[ ] 🟡 Открыть «💪 Тренировки» → «⭐ Мои упражнения» — добавить несколько упражнений
[ ] 🟡 Провести самостоятельную тренировку («Моє тренування»), записать подходы
[ ] 🟡 Обновить замеры: убедиться что все поля с подсказками доступны
[ ] 🟢 Заполнить «Бажані параметри тіла», проверить что сохранились
[ ] 🟡 Найти несколько заведений через «Клубы, студии»: поиск по области, по населённому пункту, по названию

Этап 3 — Расписание и финансы (дни 15–21)
> Задача: стресс-тест расписания (отмена, перенос, отпуск), проверка отчётности и уведомлений.
1. Администратор
[ ] 🔴 Снять владельца заведения через ADM_VOWN_RM — заведение не удаляется, роль → student
[ ] 🔴 Назначить нового владельца — убедиться что предыдущий снят автоматически
[ ] 🔴 Проверить FK-целостность: слоты, планы, pricing ссылаются на реальный chat_id (не INVITE_*)
[ ] 🟡 Проверить RLS «Мои упражнения» — тренер A не видит упражнения тренера B
---
2. Владелец заведения
[ ] 🟡 Получить уведомление о прикреплении нового тренера к заведению
[ ] 🔴 Убедиться что уведомление о заведении из другого города не пришло ошибочно (таргетинг работает)
[ ] 🟢 Проверить «📜 Условия использования» для роли venue_owner — отдельный текст 2.1/2.2
---
3. Тренер
[ ] 🟡 Создать перерыв в расписании («Мои перерывы/отпуска»)
[ ] 🔴 Создать отпуск на несколько дней
[ ] 🔴 Убедиться что ученик не может записаться на дни отпуска
[ ] 🔴 Убедиться что календарь переноса не предлагает дни отпуска
[ ] 🔴 Отменить тренировку (❌): ученик получает уведомление, слот освобождается
[ ] 🔴 Перенести тренировку (🔄): ученик получает запрос на подтверждение
[ ] 🟡 Открыть «Отчёты» → «Количество тренировок» — фильтр по периоду, разбивка по ученикам
[ ] 🔴 Открыть «Отчёты» → «Сумма доходов» — разбивка по ученикам и валютам корректна
[ ] 🟢 Проверить ревизию плана: cron присылает напоминание после 6 недель с активации
---
4. Ученик с тренером
[ ] 🔴 Запросить перенос тренировки самостоятельно
[ ] 🔴 Тренер отклоняет перенос (SCH_CR_NO) — ученик получает уведомление
[ ] 🔴 Тренер подтверждает перенос (SCH_CR_OK) — статус BOOKED на новый слот
[ ] 🔴 Попробовать записаться на слот в дни отпуска тренера — запись заблокирована
[ ] 🟡 Проверить «Мой тренер» — карточка с документами, локацией, контактами
[ ] 🟢 Для женщин: «Профіль» → «🌸 Цикл і менопауза» — редактирование данных работает
---
5. Пользователь-одиночка (без тренера)
[ ] 🟡 Прикрепиться к заведению через «Клубы, студии» — заведение сохраняется в профиле
[ ] 🟡 Получить уведомление о новом заведении в своём городе (администратор добавляет тестовое)
[ ] 🟡 Открыть карточку заведения — видны тренеры с кнопками перехода в публичный профиль
[ ] 🟢 Перейти в публичную карточку тренера через deep link pvch_<chatId>

Этап 4 — AI, уведомления, финальная проверка (дни 22–30)
> Задача: проверить AI-функции и fallback, провести сквозное тестирование всех ролей перед открытым запуском.
1. Администратор
[ ] 🟡 Проверить `ai\_generated\_content`: есть записи plan_comment, reminder, failure_analysis, body_analysis
[ ] 🔴 Проверить логи Railway — нет критических ошибок за весь период теста
[ ] 🔴 Проверить что cron /cron/reminders не создаёт дубликаты (таблица reminders_sent)
[ ] 🟡 Проверить cron /cron/plan-revision — напоминания тренерам об обновлении планов отправляются
[ ] 🔴 Финальный прогон: пользователи, инвайты, заведения — данные корректны, дублей нет
---
2. Владелец заведения
[ ] 🔴 Сквозной тест: открыть бот после всех изменений — меню, карточка заведения, список тренеров
[ ] 🟡 Убедиться что роль venue_owner сохраняется после всех изменений в заведении
[ ] 🟢 Проверить «Связь с разработчиком» — ссылка/переход работает
---
3. Тренер
[ ] 🟡 Получить AI-напоминание от бота (персонализированный текст при AI_ENABLED=true)
[ ] 🔴 При AI_ENABLED=false: шаблонное напоминание всё равно отправляется, бот не падает
[ ] 🟡 Включить AI обратно — новый авто-подобранный план содержит комментарии «💬 Тренер»
[ ] 🟡 Архивировать ученика: в «Мои ученики» не отображается, доступен через «Архив учеников»
[ ] 🟡 Активировать архивного ученика — возвращается в основной список
[ ] 🟢 Полный прогон «Подсказок»: чеклист «В первую очередь» (8 пунктов), все кнопки ведут в нужные разделы
---
4. Ученик с тренером
[ ] 🟡 Намеренно не выполнить план 2 раза подряд: target_weight снижается на 10%, тренер получает уведомление
[ ] 🟡 AI-анализ невыполнения (AI_ENABLED=true): ученик получает student_message, тренер получает coach_message
[ ] 🔴 Fallback: при AI_ENABLED=false тренировка сохраняется без ошибок, AI-сообщения просто не отправляются
[ ] 🟡 Получить напоминание о тренировке — персонализированный текст (AI) или шаблон (fallback)
[ ] 🔴 Сквозной тест: записаться → тренировка → завершить → проверить данные в bot_training_data
---
5. Пользователь-одиночка (без тренера)
[ ] 🟢 Проверить «💡 Подсказки» — solo-набор отличается от набора ученика с тренером
[ ] 🟡 Добавить бажані параметри тела, проверить AI-анализ целей vs текущее состояние
[ ] 🟡 Открыть deep link venue_<id> — карточка заведения открывается корректно
[ ] 🔴 Сквозной тест: регистрация → замеры → поиск заведения → самостоятельная тренировка → завершить

Критерии готовности к открытому запуску
[ ] 🔴 Все пункты 🔴 КРИТИЧНО выполнены без блокирующих багов
[ ] 🔴 Нет потери данных при активации инвайт-кодов (FK-целостность проверена)
[ ] 🔴 Расписание: запись, отмена, перенос, отпуск — без дублей и конфликтов
[ ] 🔴 AI-функции деградируют без ошибок при AI_ENABLED=false (fallback работает)
[ ] 🟡 Уведомления (напоминания, новые заведения, тренер в заведении) не дублируются
[ ] 🟡 Все роли прошли сквозной тест: регистрация → основной сценарий → завершение
[ ] 🟡 Отчёты тренера: суммы и количество тренировок совпадают с реальными данными
[ ] 🟢 Подсказки, условия использования, AI-комментарии к плану — отображаются корректно
